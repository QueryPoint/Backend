# Каталог тестовых данных

| Каталог | Что хранить | Назначение |
|---|---|---|
| `fixtures/valid` | текстовый PDF, многостраничный PDF, простой DOCX | успешная загрузка и поиск |
| `fixtures/invalid` | TXT/JPG/PNG/ZIP, файл с поддельным расширением | проверка MIME/формата |
| `fixtures/corrupted` | битые PDF/DOCX | ошибки извлечения |
| `fixtures/oversized` | PDF/DOCX >20MB | граница размера |
| `fixtures/security` | docm, zip bomb, traversal-имя, недопустимые сигнатуры | будущие security-проверки |
| `fixtures/search` | документы с эталонными русскими запросами | Precision@3 и highlight |

Большие и бинарные файлы не включаются в git без необходимости. Их можно сгенерировать локально в тестовой среде или хранить через Git LFS.
